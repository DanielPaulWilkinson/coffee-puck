# Changelog

## 1.1.0 (2026-10-28)
- New regal autumn theme: espresso, oxblood and burnished gold on parchment, with subtle grain.
- Crest logo, full icon set (SVG, PNG 16–512, maskable, apple-touch, favicon.ico), and a social share card.
- Open Graph and Twitter metadata, plus iOS web-app meta tags.
- Installable PWA: manifest id and scope, shortcuts, and narrow and wide screenshots.
- Edit and delete brews and beans.
- Import a backup by merging or replacing.
- ★ Best recipe badge.
- Pour and steam animation on save, and an autumn empty-state illustration (both respect reduce motion).
- Privacy policy page.
- Docs: user guide, brewing guide, deploy, contributing.
- Removed the GitHub Actions deploy workflow. Deploying is now manual (see DEPLOY.md).

## 1.0.0 (2026-10-28)
- Rebuilt coffee-puck as an offline brew journal: new brew with prefill, dial-in hints, bean shelf, bean detail chart, history, and JSON backup.
- Removed the old admin app, API and scraper.
